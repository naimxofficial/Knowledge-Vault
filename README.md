# 🧠 Knowledge Vault

> **Structured Thinking, Not Just Note-Taking.**

Knowledge Vault is a modern product landing page for a personal knowledge management app. It's designed to convert visitors into early access signups by clearly communicating the problem with traditional note-taking and positioning Knowledge Vault as a structured thinking environment — not just another notes app.

🌐 **Live Site:** *https://naimxofficial.github.io/Knowledge-Vault/*

---

## ✨ Features

| Feature | Details |
|--------|---------|
| 🏠 **Hero Section** | Full-screen background image, "Early Access Now Open" badge, and two CTA buttons — Start Building Your Vault & See How It Works |
| ⚠️ **Problem Section** | 4 hover-animated problem cards — Scattered Notes, Bookmark Overload, No Idea Connections & Forgetting What You Learned |
| 🧠 **Second Brain Section** | Split layout with knowledge diagram image and 4 green checkmark feature highlights |
| 🎟️ **Early Access CTA** | Full-width section with "Get Early Access" button and "Free • No credit card needed" note |
| 🔗 **Footer** | KV logo, X, LinkedIn & Facebook social links, and copyright line |
| 🃏 **Card Hover Animation** | Problem cards lift up with shadow on hover via CSS transition |
| 🎨 **Green & Dark Navy Theme** | Consistent #30b868 green accent on dark navy (#001931) backgrounds |
| 📱 **Fully Responsive** | Clean layout across mobile, tablet, and desktop |
